# Projet_bio - CryptoBox (brique 1)

Outil de chiffrement classique codé en Python, sans bibliothèque de cryptographie.

Auteurs : Mohamed Moncef Boulmaache et Amine Sissaoui (binôme 41)

## Fonctionnalités
- César : chiffrer, déchiffrer, force brute (25 clés)
- Substitution : chiffrer et déchiffrer avec une clé de 26 lettres
- Transposition par colonnes : chiffrer et déchiffrer avec un mot-clé

## Utilisation
    python cryptobox.py              # menu interactif
    python cryptobox.py test         # tests avec les exemples du sujet
    python cryptobox.py challenge    # déchiffrement du message du TP

## Conventions
Lettres majuscules A-Z, sans espaces ni accents (le programme nettoie le texte automatiquement).
